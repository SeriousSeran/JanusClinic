# Homepage Instagram links

Added a labelled Stay connected section on the homepage, between the Janus approach and clinic information. It links exactly to the two Instagram profile URLs supplied by the owner: https://www.instagram.com/dr.jayaruwanbandara/ and https://www.instagram.com/janus_clinic/.

Rounded rose link cards show the account names, handles, Instagram camera symbol and external-link arrow. They open in a new tab with noopener/noreferrer and an explicit accessible label. Hover uses a small lift, icon colour transition and arrow movement; reduced-motion disables transforms and transitions. Cards stack on mobile and preserve keyboard focus visibility. There are no embeds, external scripts, follower counts, copied posts or claims about account verification.

Reference: Ohio State Buckeye UX Design System, Social Media Links, https://bux.osu.edu/page-elements/social-media-links (consulted 6 November 2026). Used consistent social-link styling, text labels and external-link identification. No social messages were sent.

Validation: TypeScript, source audit and prefixed static build/link checks. Managed browser visual QA is unavailable. Published only to the existing owner-private review site; GitHub unchanged.
